# AI 智能体能力边界审查

用于解决“这个能力到底是不是智能体做的”问题，尤其适用于预案生成、数字问数、综合研判和设备联动。

## 能力分类

逐项归入以下层级：

| 层级 | 主要职责 |
|---|---|
| AI 智能体 | 理解任务、规划步骤、组合工具、推理、解释、推荐 |
| LLM | 自然语言理解与生成 |
| 规则引擎 | 确定性规则、阈值、条件判断 |
| 算法模型 | 检测、识别、预测、评分、分类 |
| 数据服务 | 查询、聚合、统计、指标计算 |
| RAG | 非结构化文档知识检索 |
| 知识图谱 | 实体、属性、关系组织与关联查询 |
| 工作流引擎 | 流程编排、审批、状态推进 |
| 后端服务 | 权限、业务状态、持久化、日志、审计 |
| 前端 | 页面展示、图表渲染、交互 |
| 设备平台 | 指令转换、下发、设备控制、状态采集 |
| 人工 | 审核、确认、干预、最终决策 |

## 审查规则

必须重点识别：

1. “智能体自主查询海量数据”是否实际依赖数据库、搜索引擎或数据中台
2. “智能体自动完成设备联动”是否实际只是生成策略，执行仍依赖平台和设备系统
3. “智能体判断事件”是否实际依赖视觉/交通算法
4. “智能体生成图表”是否只是生成图表配置，实际渲染由前端完成
5. “智能体生成报告”与文件导出、模板渲染是否被混为一谈
6. “智能体准确性校验”是否需要确定性规则、仿真或人工审核
7. “秒级查询”“高并发”“海量索引”等性能指标是否被错误归到大模型
8. 事实型结论是否有真实数据来源

## 智慧隧道特别规则

### 预案生成
智能体可负责事件理解、预案匹配、内容生成、联动策略建议；平台负责权限、流程、存储、指令下发、状态管理、日志审计；设备平台负责真实设备执行；高风险动作应保留人工确认。

### 数字问数
LLM/智能体负责理解问题和组织答案；真实数据查询、聚合、统计应由数据服务完成；图表渲染由前端完成。禁止模型自行生成业务事实。

### 综合研判
必须区分：原始事实、算法结果、规则判断、智能体综合分析、可能原因、建议措施。模型推测不得写成确定事实。

## 输出格式

输出“能力边界矩阵”，至少包含：

功能项｜材料原描述｜真实能力归属｜智能体职责｜依赖能力｜人工是否参与｜当前问题｜建议修改表述｜验收主体

最后输出：

- 边界清晰项
- 边界混乱项
- 高风险表述
- 建议重新定义的功能
- 必须与研发/甲方确认的问题
